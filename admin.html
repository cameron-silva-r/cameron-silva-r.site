Publier une note

Rédige directement ici, avec mise en forme (gras, italique, souligné, images), puis clique sur « Publier » : la note est écrite dans le dépôt GitHub et le site se met à jour automatiquement en général en moins d'une minute. Aucun fichier à échanger, aucun HTML à écrire.

Pourquoi une connexion est demandée : ce site est hébergé de façon statique (GitHub Pages), sans serveur ni base de données. Pour que cette page puisse écrire à ta place dans le dépôt, il faut une preuve que c'est bien toi — sinon n'importe quel visiteur pourrait modifier le site. Le jeton ci-dessous sert uniquement à l'étape « Publier », il ne verrouille pas l'accès à cette page.

1. Connexion GitHub

Crée un jeton sur github.com → Settings → Developer settings → Fine-grained tokens, limité au seul dépôt cameron-silva-r.site, avec la permission Contents: Read and write uniquement, et une expiration courte (ex. 90 jours).

2. Informations de la note

Généré depuis le titre, modifiable. Utilisé dans le lien de la note.

3. Contenu de la note

Sélectionne du texte puis clique sur G / I / S pour le mettre en forme. « Image » envoie directement un fichier (PNG, JPG, WebP, SVG) dans le dépôt et l'insère à l'endroit du curseur.
