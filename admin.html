Générateur de notes (outil local)

Cette page n'est pas un vrai "mode admin" connecté au site : GitHub Pages est un hébergement statique, sans base de données ni serveur. Ce formulaire te permet simplement de remplir les informations d'une note et de générer le fichier de données correspondant, sans écrire de HTML toi-même.

Comment ça marche :

1. Choisis la langue, remplis les champs, coche les thèmes.

2. Clique sur « Générer et télécharger le fichier JSON ».

3. Remplace le fichier téléchargé dans assets/data/ (même nom que l'ancien).

4. Commit + push (je peux le faire pour toi si tu me le demandes).

Le site (blog.html, l'accueil et les pages de note) lit automatiquement ce fichier : aucune page HTML à créer.

Limite technique : ouverte directement en local (double-clic sur le fichier), cette page ne peut pas toujours relire le fichier JSON existant (restriction de sécurité des navigateurs sur les fichiers locaux). Tu peux quand même créer une nouvelle note sans problème. Pour éditer une note déjà publiée avec pré-remplissage automatique, ouvre plutôt cette page directement sur le site en ligne : https://cameron-silva-r.github.io/cameron-silva-r.site/admin.html. Cette page n'est reliée depuis aucun menu, elle reste donc discrète.
